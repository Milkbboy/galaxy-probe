# Sys-UI Concept Draft

> 작성일: 2026-06-26  
> 기준 자료: GitHub Wiki `6월 24일` UI 레퍼런스  
> 링크: https://github.com/Milkbboy/galaxy-probe/wiki/6%EC%9B%94-24%EC%9D%BC
> 구현 계획: [Sys-UI-ImplementationPlan.md](Sys-UI-ImplementationPlan.md)

## 1. 목적

이 문서는 Drill-Corp의 아웃게임 UI 작업을 시작하기 위한 초안이다.  
위키의 2026-06-24 UI 레퍼런스를 기준으로 전체 UI 컨셉, 공통 스타일, 화면별 구성, 우선 작업 순서를 정리한다.

현재 위키 이미지는 최종 사양서라기보다 "비주얼 방향 + 주요 화면 구성 기준"에 가깝다. 따라서 1차 작업은 기능을 완성하기보다, 공통 UI 언어를 먼저 맞추고 각 화면을 같은 톤으로 정렬하는 것을 목표로 한다.

## 2. 전체 UI 컨셉

### 키워드

- 픽셀아트 SF
- 우주 채굴
- 산업용 금속 HUD
- 채굴선/드릴 머신/무기 제작소
- 어두운 우주 배경 + 발광 노드 + 두꺼운 기계식 패널

### 최종 방향

현재 구현안의 배치와 기능 구조는 유지하되, 비주얼은 위키 레퍼런스처럼 "금속 프레임, 베벨, 글로우, 픽셀 HUD 질감"을 입힌다.

즉, 최종 목표는 다음 조합이다.

| 구분 | 방향 |
|---|---|
| 정보 구조 | 현재 구현안의 단순한 화면 구성 유지 |
| 시각 스타일 | 레퍼런스 이미지의 픽셀아트 SF 패널로 통일 |
| 버튼/패널 | 두꺼운 금속 프레임, 녹회색/카키 계열, 어두운 내부 면 |
| 강조 | 선택/활성은 노랑 또는 청록 글로우 |
| 잠금 | 어두운 패널 + 붉은 `LOCKED` 강조 |
| 텍스트 | D2Coding TMP + 외곽선/그림자 적용 |

## 3. 공통 스타일 가이드

### 색상 팔레트

| 용도 | 추천 색상 | 비고 |
|---|---|---|
| 배경 | `#151426`, `#101722`, `#0A1018` | 어두운 우주/패널 배경 |
| 기본 패널 | `#2B332E`, `#384238`, `#4E5F4B` | 녹회색 금속 |
| 금속 외곽 | `#6D6A5C`, `#8A7B62`, `#A28B63` | 베벨/프레임 |
| 내부 어둠 | `#050812`, `#11141D`, `#191B28` | 리스트/비활성 영역 |
| 활성 녹색 | `#7ED78E`, `#9EE7A6` | 활성화/장착 완료 |
| 선택 노랑 | `#FFD35A`, `#FFB84A` | 선택 테두리/구매 가능 |
| 청록 글로우 | `#67E6E4`, `#7DDFFF` | 기술/노드 연결선 |
| 잠금 붉은색 | `#C8685E`, `#E0756E` | Locked/재화 부족 |
| 본문 텍스트 | `#E8E0D0`, `#CFC7B6` | 픽셀 HUD 가독성 |

### 폰트

- TMP 생성 시 `TMPFontHelper.ApplyDefaultFont(tmp)`를 사용한다.
- 기본 폰트는 `D2Coding-Ver1.3`.
- 큰 버튼/타이틀은 다음 효과를 기본으로 둔다.
  - 진한 외곽선
  - 약한 그림자
  - 약간의 베벨 느낌이 나는 밝은 상단/어두운 하단 색상

### 공통 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `MetalPanel` | 화면의 큰 프레임 패널. 두꺼운 외곽선과 어두운 내부 면을 가진다. |
| `MetalButton` | 메인 메뉴, BACK, START, EMPLOY 등에 사용하는 기본 버튼. |
| `ResourceBar` | 우측 상단 자원 보유량. 광석/보석/크레딧 등 아이콘 + 수량. |
| `LockBadge` | 잠금 상태 표시. 붉은 띠 또는 어두운 오버레이 + `LOCKED`. |
| `SelectionGlow` | 현재 선택된 카드/노드에 노랑 글로우 테두리 적용. |
| `NodeButton` | 무기 제작/옵션 트리에서 쓰는 발광 사각 노드. |
| `ConfirmPopup` | 종료 확인 등 공통 모달. 배경 딤 + 금속 프레임 + YES/NO. |

## 4. 화면별 초안

### 4.1 메인 메뉴

위키 레퍼런스 기준으로 가장 완성된 화면이다.  
우주 배경과 드릴 함선 일러스트를 중심으로 두고, 메뉴 버튼을 하단과 우측 상단에 배치한다.

필수 요소:

- 중앙/상단 타이틀 로고
- 화면 중앙 하단 `Press Any Key To Start`
- 하단 3버튼
  - `UPGRADES`
  - `SELECT CHARACTER`
  - `CRAFTING`
- 우측 상단 2버튼
  - `SETTINGS`
  - `EXIT GAME`

작업 방향:

- 하단 버튼은 같은 높이와 같은 프레임 두께로 통일한다.
- 버튼마다 아이콘을 함께 둔다.
- 시작 안내 문구는 흰색 텍스트 + 검은 외곽선으로 배경 위에서도 읽히게 한다.
- `EXIT GAME` 클릭 시 현재 플랫 팝업 대신 공통 `ConfirmPopup`을 사용한다.

### 4.2 업그레이드 화면

레퍼런스는 중앙 드릴 머신, 주변 업그레이드 노드, 우측 상세 리스트를 함께 보여준다.  
현재 구현안은 중앙 드릴 머신 + 좌우 목록 구조이므로, 1차 구현은 현재 구조를 유지하며 스타일만 통일한다.

필수 요소:

- 우측 상단 자원 보유량
- 중앙 드릴 머신 이미지
- 굴착기 강화 메뉴
- 보석 채집 메뉴
- 무기 업그레이드 및 해금 메뉴
- 우측 하단 `BACK`

1차 배치:

- 중앙: 드릴 머신 이미지
- 좌측: 무기/기본 해금 카드
- 우측: 굴착기 강화 및 보석 채집 리스트
- 우측 상단: `ResourceBar`
- 우측 하단: `BACK`

스타일:

- 리스트 행은 어두운 금속 슬롯으로 만든다.
- 구매 가능 항목은 노랑 또는 녹색 비용 강조.
- 재화 부족 항목은 어둡게 낮추고 비용만 붉게 표시한다.
- 선택된 항목은 청록 외곽선 또는 노랑 글로우를 사용한다.

### 4.3 캐릭터 화면

레퍼런스는 캐릭터 카드형 UI가 명확하다.  
현재 구현안은 카드 사이에 장비 버튼을 배치하고 있으므로, 카드 자체를 레퍼런스 톤으로 바꾸는 것이 우선이다.

필수 요소:

- 우측 상단 자원 보유량
- 캐릭터 카드
- 캐릭터 해금/선택 버튼
- 캐릭터 고유 장비 해금 버튼
- 우측 하단 `BACK`

카드 상태:

| 상태 | 표현 |
|---|---|
| 선택됨 | 노랑 글로우 테두리 + `SELECTED` 또는 `장착 완료` |
| 보유 | 녹색 `UNLOCKED` + 선택 가능 버튼 |
| 미보유 | 붉은 `LOCKED` + 해금 비용 |
| 재화 부족 | 어두운 버튼 + 붉은 비용 |

작업 방향:

- 캐릭터 일러스트 영역, 이름, 역할/설명, 해금 비용을 카드 안에 정리한다.
- 현재 파란 임시 버튼은 모두 금속 버튼 스타일로 교체한다.
- 고유 장비 버튼은 카드 옆 보조 슬롯으로 유지하되, 작고 명확한 금속 슬롯으로 정리한다.

### 4.4 무기 제작 화면

현재 미구현 화면이며, 레퍼런스는 노드 트리형 UI다.  
최종적으로는 무기 해금/강화 트리를 "발광 연결선 + 사각 노드"로 표현한다.

필수 요소:

- 상단 제목: `WEAPON CRAFTING & UPGRADE TREE`
- 우측 상단 자원 보유량
- 중앙 무기 미리보기
- 무기별 트리 노드
- 현재 무기 슬롯
- 제작 재료 표시
- `BACK`

1차 구현 범위:

- 실제 데이터 연결 전, 3개 무기 라인 정도의 정적 트리 구성
- 노드 상태 3종 구현
  - 활성/보유
  - 해금 가능
  - 잠김
- 노드 클릭 시 우측 또는 하단 상세 패널 표시

스타일:

- 기본 노드: 어두운 금속 사각형 + 아이콘
- 활성 노드: 녹색 글로우
- 선택 노드: 노랑 글로우
- 연결선: 청록/녹색 발광 라인
- 잠금 노드: 회색 오버레이 + 자물쇠

### 4.5 옵션 화면

현재 미구현 화면이며, 레퍼런스는 무기 제작과 같은 트리형 레이아웃을 사용한다.  
다만 실제 옵션은 트리보다 카테고리 패널 구조가 유지보수에 유리하다.

필수 카테고리:

- Display
- Language
- Audio & Sound
- Gameplay & Accessibility

1차 구현 범위:

- 해상도/창모드
- 사운드 볼륨
- 효과음 볼륨
- 언어 선택 자리
- 조작/커서 옵션 자리
- `BACK`

스타일:

- 큰 카테고리는 금속 헤더 패널로 구분한다.
- 토글/슬라이더/드롭다운은 Unity 기본 UI 느낌이 드러나지 않도록 금속 슬롯 안에 넣는다.
- 설정값은 즉시 반영하되, 저장은 별도 JSON 저장 정책에 맞춘다.

### 4.6 게임 종료 팝업

현재 구현안은 배경에 단색 사각형 모달이 올라와 있어 전체 UI 컨셉과 맞지 않는다.  
가장 먼저 리스킨하면 체감 개선이 큰 화면이다.

필수 요소:

- 배경 딤 처리
- 금속 프레임 팝업
- 제목: `Exit Game`
- 본문: `게임을 종료하시겠습니까?`
- 버튼: `YES`, `NO`

작업 방향:

- `NO`를 기본 선택/포커스 상태로 둔다.
- `YES`는 붉은 계열 또는 주황 계열 강조를 사용한다.
- 모달 외부 클릭 또는 ESC는 `NO`와 동일하게 닫기 처리한다.

## 5. 구현 우선순위

### 1차: 공통 스타일 기반

목표는 모든 화면에서 같은 UI 언어가 보이게 만드는 것이다.

1. 공통 색상/폰트/패널 규칙 정리
2. `MetalPanel`, `MetalButton`, `ResourceBar`, `ConfirmPopup` 프리팹 또는 생성 유틸 준비
3. D2Coding TMP 적용 누락 제거
4. 버튼 hover/pressed/disabled 상태 정의

### 2차: 메인 메뉴 + 종료 팝업

가장 작은 범위에서 전체 톤을 검증한다.

1. 메인 메뉴 버튼 스타일 통일
2. 설정/종료 버튼 우측 상단 정렬
3. `Press Any Key To Start` 연출 정리
4. 종료 확인 팝업 리스킨

### 3차: 업그레이드/캐릭터 리스킨

이미 구현 진행 중인 화면의 임시 UI를 레퍼런스 스타일로 교체한다.

1. 우측 상단 자원 표시 공통화
2. `BACK` 버튼 공통화
3. 업그레이드 리스트 금속 슬롯화
4. 캐릭터 카드 상태 표현 정리
5. 해금/선택/잠금 상태 연결

### 4차: 무기 제작/옵션 골격

미구현 화면은 데이터 연결보다 시각/레이아웃 골격을 먼저 만든다.

1. 무기 제작 노드 트리 정적 프로토타입
2. 옵션 카테고리 패널 정적 프로토타입
3. 실제 데이터/저장 연결

## 6. 구현 시 주의사항

- New Input System을 사용한다. `UnityEngine.Input` 레거시 API는 사용하지 않는다.
- TMP 생성 시 반드시 D2Coding 폰트를 적용한다.
- `Resources` 폴더 사용은 최소화한다.
- 런타임 데이터 저장은 JSON 기준으로 설계한다.
- UI 오브젝트 자동 생성 에디터 툴을 만들 경우, 생성된 TMP에도 D2Coding을 적용한다.
- 화면 기준 해상도는 1920x1080으로 잡되, 앵커와 스케일러를 통해 비율 변화에 대응한다.
- 플랫 컬러 임시 UI는 최종 스타일로 간주하지 않는다.

## 7. 미정 사항

다음 항목은 현재 위키만으로는 최종 확정이 어렵다. 1차 구현에서는 임시값을 두고, 추후 기획/데이터 연결 시 확정한다.

- 자원 종류 최종 명칭과 아이콘
- 캐릭터 최종 이름/설명/해금 비용
- 고유 장비 종류와 해금 조건
- 무기 제작 트리의 실제 노드 구조
- 옵션 화면의 실제 저장 항목
- 버튼 사운드/전환 애니메이션
- 키보드/패드 포커스 이동 규칙

## 8. 1차 완료 기준

- 메인 메뉴, 업그레이드, 캐릭터, 종료 팝업이 같은 금속 HUD 스타일로 보인다.
- 모든 TMP 텍스트에 D2Coding이 적용되어 있다.
- 자원 표시와 `BACK` 버튼이 화면마다 같은 위치/스타일로 반복된다.
- 선택/잠금/해금 가능/재화 부족 상태가 색상만 봐도 구분된다.
- 1920x1080 기준으로 텍스트와 버튼이 겹치지 않는다.
